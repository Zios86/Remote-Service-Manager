# Remote Service Manager

Графическая программа для удалённого управления службами и процессами Windows и Linux с рабочего компьютера Windows.

Актуальная версия: **2.2.0**.

## Скачать

[Remote-Service-Manager-v2.2.0.zip](dist/Remote-Service-Manager-v2.2.0.zip)

Распакуйте архив и запустите `Запустить.bat`.

## Возможности

- получение полного списка служб Windows и systemd;
- смысловые группы EAS4, MARS, базы данных, печать, мониторинг и другие;
- групповые чекбоксы, сворачивание и фильтрация категорий;
- запуск, остановка, перезапуск и изменение типа запуска;
- защита критических служб;
- снимки состояния и откат последней операции;
- диагностика служб и журналов событий;
- онлайн-мониторинг процессов, CPU и памяти;
- безопасное завершение выбранных процессов;
- экспорт в CSV и журналирование операций.

## Подключение

### Windows

Используется постоянная сессия WinRM/WS-Man с Kerberos. Указывайте DNS-имя компьютера, например `R78-191036-W01`. IP-адрес намеренно не принимается, поскольку Kerberos не может проверить сервер по IP.

Поддерживается текущая доменная учётная запись или отдельно введённый `PSCredential`. Автоматический переход на NTLM и изменение `TrustedHosts` не выполняются.

### Linux

Используется штатный OpenSSH-клиент Windows и `systemd`. Поддерживается имя обычной или доменной учётной записи, SSH-ключ и `ssh-agent`.

SSH работает со строгой проверкой ключа узла, без PTY, Agent Forwarding, X11 и перенаправления портов. Для административных операций требуются `root` или точечные права `sudo -n`.

Подробная подготовка приведена в [LINUX_SETUP.txt](LINUX_SETUP.txt).

## Требования

- Windows 10/11;
- Windows PowerShell 5.1;
- доступный WinRM для Windows-компьютеров;
- компонент Windows OpenSSH Client для Linux-компьютеров;
- Linux с systemd и необходимыми правами sudo.

## Проверка

Для версии 2.2.0 проверены структура XAML и JSON, UTF-8 BOM для PowerShell 5.1, контрольные суммы запускаемых модулей и целостность ZIP. Фактические операции необходимо сначала проверить на тестовом Windows/ALT Linux в корпоративной сети.

## Безопасность

BAT проверяет SHA-256 исполняемых PowerShell-файлов. Для промышленного распространения рекомендуется дополнительно подписать скрипты корпоративным сертификатом Authenticode и применять WDAC/AppLocker.
