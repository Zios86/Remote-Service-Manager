# Проверка изменений

## Обязательный минимум

Выполнять после каждого изменения перед публикацией.

### 1. Синтаксис PowerShell 5.1

```powershell
$errors = $null
[System.Management.Automation.Language.Parser]::ParseFile(
    "$PWD\Remote-Service-Manager.ps1", [ref]$null, [ref]$errors
) | Out-Null
$errors

$errors = $null
[System.Management.Automation.Language.Parser]::ParseFile(
    "$PWD\Linux-Remote.ps1", [ref]$null, [ref]$errors
) | Out-Null
$errors
```

Ожидается пустой вывод ошибок.

### 2. JSON

```powershell
$config = Get-Content .\service-groups.json -Raw -Encoding UTF8 | ConvertFrom-Json
if ($config.schemaVersion -ne 2) { throw 'Wrong configuration schema' }
if (-not $config.groups -or -not $config.protectedServices) { throw 'Incomplete configuration' }
```

### 3. Контрольные суммы

```powershell
Get-FileHash .\Remote-Service-Manager.ps1 -Algorithm SHA256
Get-FileHash .\Linux-Remote.ps1 -Algorithm SHA256
```

Обе суммы должны точно совпадать со значениями в `Запустить.bat`.

### 4. Запуск

- Запустить только `Запустить.bat`.
- Убедиться, что заголовок показывает версию из `VERSION.txt`.
- Проверить запуск из локальной папки и UNC-пути.
- Убедиться, что при повреждении PS1 BAT блокирует запуск и оставляет сообщение на экране.

## Матрица ручного smoke-теста

| Сценарий | Ожидаемый результат |
|---|---|
| Windows, текущая доменная УЗ, DNS-имя | Kerberos-сессия и полный список служб |
| Windows, IP-адрес | Понятный отказ до подключения |
| Windows, неверное имя | Старый список очищен, показана ошибка |
| Linux, известный host key и ключ/agent | Список systemd-служб |
| Linux, неизвестный или изменённый host key | Подключение заблокировано OpenSSH |
| Linux без обязательной команды | Названа отсутствующая команда |
| Чекбокс группы | Выбраны все службы, включая свёрнутую группу |
| Start/Stop/Restart нескольких служб | Один пакет, проверка каждой службы и итоговое окно |
| Изменение типа запуска | Фактический новый тип отображён после проверки |
| Защищённая служба | Операция блокируется до удалённой команды |
| Мониторинг процессов | UI не зависает; CPU обновляется со второго Linux-снимка |
| Завершение процесса | PID повторно проверен; результат записан в аудит |
| CSV с опасной строкой | Excel показывает текст, формула не выполняется |
| Откат | Восстанавливается снимок только текущей ОС и компьютера |

## Регрессия интерфейса

- изменить ширину и высоту окна;
- проверить перенос кнопок и доступность правого края;
- свернуть и развернуть все категории;
- проверить EAS4 первой, MARS второй;
- проверить поиск, фильтр состояния и фильтр группы;
- открыть и закрыть мониторинг несколько раз;
- убедиться, что скрытые колонки служб не появились снова.

## Перед релизом

1. Обновить версию и changelog.
2. Пересчитать BAT-хеши.
3. Собрать ZIP из чистого каталога проекта.
4. Выполнить проверку целостности ZIP.
5. Открыть ZIP, распаковать в новую папку и запустить BAT.
6. Проверить хотя бы один тестовый Windows и один тестовый ALT Linux либо явно зафиксировать непроверенную платформу.
