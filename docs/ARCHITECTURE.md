# Архитектура

## Стиль

Приложение остаётся портативным монолитом PowerShell/WPF с отдельным Linux-адаптером. Это осознанный компромисс: один каталог запускается без установки приложения и дополнительных библиотек.

## Слои

1. **Presentation** — XAML, обработчики событий, таблицы и итоговые окна.
2. **Application** — выбор объектов, подтверждение, снимок, маршрутизация, проверка результата и аудит.
3. **Windows transport** — постоянная PSSession, WinRM job и CIM/Get-Service внутри цели.
4. **Linux transport** — отдельный процесс OpenSSH и команды systemd/ps/journalctl.
5. **Configuration and storage** — JSON в каталоге приложения; изменяемые данные в LocalAppData.

## Нормализованные модели

Обе ОС должны возвращать в UI одинаковые основные поля службы: `Name`, `DisplayName`, `State`, `StartMode`, `StartName`, `ProcessId`, `PathName`, `Group`, `IsChecked`.

Процессы обеих ОС используют: `ProcessId`, `Name`, `StartIdentity`, `CpuPercent`, `MemoryMB`, `DiskMBps`, `ThreadCount`, `HandleCount`, `IsChecked`.

Если метрика на платформе недоступна, соответствующая колонка скрывается; запрещено показывать выдуманный показатель как фактический.

## Инварианты

- После неудачного подключения в UI не остаются данные предыдущей цели.
- В один момент выполняется не более одной команды соответствующего транспорта.
- Любая удалённая операция имеет локальный и удалённый тайм-аут.
- Результат определяется повторным чтением состояния, а не только кодом возврата команды.
- Операция над защищённым объектом блокируется до удалённого вызова.
- PID проверяется по имени и времени старта непосредственно перед завершением.
- UI не является источником полного списка: операции выбирают объекты из `$script:AllServices`/`$script:AllProcesses`.

## Когда менять архитектуру

Переход на C#/.NET оправдан, если потребуется хотя бы одно из следующего: полноценная отмена асинхронных операций, несколько параллельных целей, долгоживущие SSH-каналы, MSI/MSIX, централизованные политики или автоматические обновления. До этого перенос увеличит стоимость поставки сильнее, чем даст практической пользы.
