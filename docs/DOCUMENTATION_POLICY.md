# Правила ведения документации

## Цель

Документация должна позволять человеку, Codex или Claude безопасно продолжить проект без восстановления решений из истории чата.

## Принципы

1. **Один источник истины для каждого факта.** Версия находится в `VERSION.txt`, структура — в `PROJECT_MAP.md`, постоянные правила — в `AGENTS.md`.
2. **Инструкции ИИ короткие.** В них остаются только команды, ограничения, неочевидные решения и типовые ошибки. Подробности даются ссылками на `docs/`.
3. **Не дублировать правила.** `CLAUDE.md` импортирует `AGENTS.md`; одинаковые требования не копируются вручную.
4. **Документы рядом с изменением.** Поведение обновляет README и changelog; архитектура — карту и ADR; риск — security; новая проверка — testing.
5. **Проверяемые формулировки.** Вместо «писать безопасно» указывается конкретный запрет или команда проверки.
6. **Документировать причину.** Код показывает, что сделано; ADR объясняет, почему выбран именно этот вариант.
7. **Удалять устаревшее.** Противоречащая коду документация является дефектом и исправляется в том же изменении.

## Матрица обновления

| Изменение | Обязательные документы |
|---|---|
| Новая пользовательская функция | `README.md`, `README.txt`, `CHANGELOG.md`, `VERSION.txt` |
| Новый модуль или поток данных | `PROJECT_MAP.md`, `docs/ARCHITECTURE.md` |
| Новый протокол, право или риск | `docs/SECURITY.md`, `docs/DECISIONS.md` |
| Новая проверка или исправленная ошибка | `docs/TESTING.md`, `CHANGELOG.md` |
| Новая постоянная норма разработки | `AGENTS.md`; только Claude-специфичное — `CLAUDE.md` |
| Новый релиз | всё выше по необходимости плюс новый ZIP в `dist/` |

## Критерии качества

- ссылки и имена файлов существуют;
- версия не противоречит `VERSION.txt`;
- команды можно скопировать и выполнить;
- отсутствуют пароли, внутренние токены и персональные данные;
- карта описывает текущие модули, а не предполагаемую будущую архитектуру;
- `AGENTS.md` и `CLAUDE.md` не превращены в учебник или копию README;
- непроверенные ограничения названы прямо.

## Официальные основания

- [OpenAI: Custom instructions with AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md) — корневые и вложенные инструкции, приоритет и краткие правила code review.
- [Anthropic: How Claude remembers your project](https://code.claude.com/docs/en/memory) — назначение, область и рекомендуемый размер `CLAUDE.md`, импорт `AGENTS.md`.
- [Anthropic: Best practices for Claude Code](https://code.claude.com/docs/en/best-practices) — краткость, проверяемые команды, архитектурные решения и удаление выводимого из кода шума.
