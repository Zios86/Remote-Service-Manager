# История изменений

Формат основан на Keep a Changelog; версии проекта используют схему `MAJOR.MINOR.PATCH`.

## [Unreleased]

- Нет незавершённых пользовательских изменений.

## [2.2.0] — 2026-09-11

### Добавлено

- Явная Kerberos-аутентификация WinRM.
- Проверка DNS-имени Windows-цели.
- Диагностика транспорта при подключении.
- Проверка схемы `service-groups.json`.
- Защита CSV и журнала от формул Excel.

### Изменено

- Удалённый профиль Windows не загружается в служебной сессии.
- SSH работает без PTY, Agent Forwarding, X11 и перенаправления портов.
- При явном SSH-ключе включён `IdentitiesOnly=yes`.
- Удалён неиспользуемый раздел профилей из конфигурации.

### Безопасность

- Исключён скрытый переход Windows-подключения на NTLM.
- Неизвестные и изменённые SSH host keys по-прежнему блокируются.

## [2.1.0] — 2026-09-10

- Транзакционное переподключение без устаревших данных.
- Тайм-ауты WinRM и SSH.
- Повторная проверка PID перед завершением.
- Интервальный CPU Linux и расширенные состояния systemd.
- Рабочие данные перенесены в LocalAppData.

## [2.0.0] — 2026-09-10

- Добавлена единая работа с Windows и Linux.
- Добавлены OpenSSH, systemd и Linux-процессы.

Подробная история версий 1.x сохранена в `README.txt`.
